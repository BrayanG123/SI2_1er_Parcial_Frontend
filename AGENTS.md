# Instrucciones del repositorio frontend

Para cualquier tarea en este repositorio, lee y aplica primero la skill local
`.agents/skills/ropa-ecommerce/SKILL.md`.

En el espacio de trabajo conjunto, el enunciado y la documentación compartida
se encuentran en `../Examen1_Ecommerce_SistemasII.md` y `../docs/`. Si esos
archivos no están disponibles porque el frontend fue clonado por separado, usa
la referencia local de la skill como contexto mínimo y no inventes requisitos.
